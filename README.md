# Everydeck Mamelodi

Everydeck Mamelodi is a premium outdoor decking and flooring business serving Mamelodi, South Africa. The project includes a modern static website landing page for advertising decking, artificial grass, cladding, and outdoor floor upgrades.

## What is included

- Promotional hero section
- Pricing packages for budget, grass, and premium composite options
- Service overview
- Customer reviews
- Gallery section using project images in the repository
- WhatsApp quote CTA connected to `079 645 1830`
- Mobile-friendly design

## Preview locally

Open `index.html` in a browser, or serve the folder with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
